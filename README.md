# Baixador de Capas 1971sportswear — Android v3 completo

Fluxo:
1. Cole a URL da categoria.
2. Analise os produtos.
3. Marque/desmarque produtos.
4. Baixe somente a imagem principal.
5. O app cria uma tela 1000x1000 com fundo branco e centraliza a imagem.
6. Gere um ZIP.

Observação: o módulo de fundo branco usa uma tela branca e centralização; ele não faz recorte inteligente do fundo da foto. Para remover fundo real de uma foto, será necessário um algoritmo/serviço de segmentação.

O app acessa diretamente as páginas e imagens. Respeite robots.txt, termos de uso e direitos autorais; utilize imagens somente quando houver autorização/licença.
